# 講義動画キャラクター素材

このフォルダを、紫ノ宮澪と麦野透のキャラクター画像の正本とする。

## フォルダ

- `masters/`: キャラクター同一性・配色・画風の基準となる全身立ち絵
  - `mio_master_fullbody.png`: 澪の配色・顔・体型の正本（レポート用背景あり）
  - `mio_master_fullbody_transparent.png`: 同じ正本の背景透過版
  - `toru_master_fullbody_v4.png`: 1400 × 1600pxの透の正本（原本D3に近い約5頭身版）
  - `toru_master_fullbody_v4_report.png`: レポート表示専用の透明余白なし派生
- `reactions/mio/`: 画面左に置く澪の動画用リアクション
- `reactions/toru-v4/`: 透の約5頭身を保った本番用リアクション（正本・動画用を兼用）
- `reactions/toru-v3/`: 旧約5.8頭身版（比較・履歴用）
- `reactions/toru-v3-video/`: 旧約5.8頭身版の動画用派生（比較・履歴用）
- `reactions/toru-v2/`: 旧7頭身版（比較・履歴用）
- `reactions/toru/`: 旧66%配置用の透リアクション（比較・履歴用）
- `contact-sheets/`: リアクションを一覧確認するための比較画像
- `../../../assets/characters/video_v3/`: PowerPointの手動配置を再現する本番動画用の
  閉口・開口素材と表情・ポーズ差分。澪は右向き説明と視聴者向きの両方、透は
  高精細な約5頭身版を採用する

## 動画用リアクションの共通仕様

- PNG（RGBA、背景透明）
- 1400 × 1600 px
- 全身正本は自然な体型を保ち、動画用派生は太もも付近より下を画面外へ流す
- 同じ人物では同じ倍率と内部の縦位置を使い、見かけの身長を揃える
- 澪は画面左から中央（右）を向く
- 透は画面右から中央（左）を向く
- キャラクターの周囲に影、発光、文字、小道具を置かない

## 澪の固定カラーパレット

2026-07-20以降は、基準画像 `mio_explain_open_palm_keyed.png` の色合いを正本とし、
マスター、閉口・開口、全ポーズ差分で次を固定する。

- 髪: 深いスモーキープラム（代表色 `#4E304F`、ハイライト `#6F4B63`）
- 瞳: 光のあるイエローオリーブ
- ニット: 落ち着いたローズマゼンタ（代表色 `#CA6F8D`）
- スカート: 黒に近いオーベルジーヌ（代表色 `#2B1A32`）
- 白衣: 温かみのある白、パイピングはワインローズ
- リボン: ダスティローズ、留め具はアンティークゴールド

新しい立ち絵を追加する時は、ポーズごとの生成判断で色を決め直さず、必ずこの正本を
色参照として与える。髪・ニット・スカートの色温度や彩度を表情に合わせて変えない。

## 画面上の身長と配置

- 本番の基準はユーザーが`Presentation1.pptx`で手動調整した1920×1080配置とする
- 澪は505×1232pxの素材キャンバスを`x=0, y=205`へ置き、画面内では下側を切る
- 透は184×1019pxの素材キャンバスを`x=1641, y=231`へ置く。透明な上余白により、人物は`y=403`から見える
- 画面内で見える基準寸法は澪約505×875px、透約184×677px
- `video_v3`の透明余白は配置情報を兼ねるため、上下左右とも自動トリムしない
- 同じ人物のリアクションを増やす時は、人物の見かけ上の高さと頭頂位置をこの基準へ合わせる
- 透の正本は約5頭身。原本D3の丸い頬、大きな目、短い首、狭いなで肩、短めの胴と手足を維持し、青年体型へ寄せない
- ポーズごとの外接矩形へ自動フィットしない（リアクション切替時の身長変化を防ぐ）

### 推奨ペア

- からかって動揺: `mio_playful_wink.png` × `toru_flustered_denial.png`
- よい指摘を褒める: `assets/characters/video_v3/metan__praise.png` × `assets/characters/video_v3/zunda__praised.png`

ハート瞳は憧れや喜びを誇張する漫画的な感情記号であり、SYNC・催眠・異常状態の
表現には使わない。常時表示せず、感情が大きく動いた瞬間の短いリアクションに限定する。
澪から透への表現は、温かい先生としての親しみと大人の余裕に留める。

口パク用の閉口・開口素材は `assets/characters/video_v3/{metan,zunda}{,_open}.png` に配置する。
生成画像全体を直接切り替えず、口元だけを局所合成した差分からパッチを抽出する。
澪と透の開口差分は閉口画像へ口元だけを合成しているため、髪・目・輪郭・服・手足は完全に静止する。

表情・ポーズ差分は `{speaker}__{pose}.png` という名前にする。同じキャラクターでは
頭頂と見かけ上の身長を固定し、澪は左端、透は右端から95pxの位置へアンカーする。

## クロマキー除去

初期リアクションでは画面外周から背景色を推定した。v4の透は緑優勢度によるソフトマットを使い、背景の濃淡ノイズを吸収しつつ黄色い服を保護した。

- 透明側しきい値: `12`
- 不透明側しきい値: `220`
- ソフトマット: 有効
- デスピル（緑かぶり除去）: 有効

v4の透では、緑優勢度 `g - max(r, b)` が0.48以上を透明側、0.30以下を不透明側として補間し、意図した緑色要素がないため `g <= max(r, b)` までデスピルした。明るい生成背景と濃紺背景の両方へ合成して輪郭を確認済み。

この値は固定値ではなく、素材ごとの調整開始点とする。髪の細線、黄緑の瞳、白衣の縁、指先は欠けや色抜けが起きやすいため、生成元のクロマキー画像を保持し、次の条件をすべて満たすまでしきい値を調整する。

- 四隅が完全に透明である
- 白・黒・中間色の背景へ合成しても緑の縁が見えない
- 髪、瞳、リボン、指、白衣の輪郭が欠けていない
- 半透明の境界が太い光彩や灰色の縁に見えない

透過後の画像だけを再加工せず、調整時は必ずクロマキー付きの生成元からやり直す。

STEP 0 ・ ブランド決定

チャンネル名とブランド素材

候補意図 / ハンドル例
ながらAI 推奨「ながら聞き」×AI ／ @nagara-ai
AIみみ耳から入れるAI ／ @ai-mimi
10分AI10分で要点 ／ @10pun-ai
耳から最前線最新を耳で ／ @mimikara-ai

概要文（匿名）例: 「AIの最新ニュースや論文を日本語のポッドキャスト風音声でお届け。通勤・作業の“ながら聞き”に。音声はAI自動生成、正確な内容は各出典をご確認ください。」

生成済み（tmp/branding/）。名前変更は gen_branding.py --name "..."
STEP 1–2 ・ アカウントとチャンネル

匿名アカウント作成 → チャンネル装飾

  • 本名と紐づかない新規 Google アカウント（または既存配下にブランドアカウント）。2段階認証を設定。
  • youtube.com → チャンネル作成 → 名前／ハンドル（例 @nagara-ai）を匿名ブランドで設定。
  • アイコン（tmp/branding/icon.png）／バナー（banner.png）／概要文をアップロード。
  • 電話番号認証を済ませる ＝ カスタムサムネ（④AIサムネ）に必須。
バナーのテキストは中央セーフエリア（1235×338）内に収めてあり、モバイルでも切れません。
STEP 3 ・ プレイリスト

カテゴリ別プレイリストを作成し ID を記入

コードのカテゴリプレイリスト名（例）
paper📄 論文ななめ聴き
news🗞 AIニュース
engineering🛠 AI開発メモ
business💰 ビジネス・キャリア
各プレイリストURLの list=PLxxxx を settings.yaml の youtube.playlists にキー名一致で記入。default は既定の playlist_id にフォールバック。
STEP 4 ・ OAuth クライアント

Google Cloud で認証情報を作成

  • console.cloud.google.com → 新規プロジェクト → YouTube Data API v3 を有効化。
  • OAuth 同意画面：User type ＝ 外部。
  • 公開ステータスを「本番（In production）」に — テスト中だとトークンが7日で失効し無人/Web実行で詰まる。機微スコープの「未確認アプリ」警告は自分用なら「詳細→続行」でOK。
  • 認証情報 → OAuth クライアントID（デスクトップアプリ）→ JSON を credentials/youtube_client_secret.json に配置。
STEP 5–6 ・ 認証と確認

匿名アカウントで認証 ＝ 公開先の切替

  • uv run automator auth youtube → ブラウザで必ず匿名アカウントを承認（既存と取り違えない）。
  • credentials/youtube_token.json が匿名アカウントのトークンに置き換わる ＝ 以降のアップロードは新チャンネルへ。
  • テスト: uv run notebooklm login → uv run automator run urls.yaml --force
  • 確認: 反映先が新チャンネル／日本語タイトル／AIサムネ／プレイリスト振り分け／概要欄に個人情報が無いこと。

あとは作るだけ 🎬

  • cookie鮮度：まとめて作る前に uv run notebooklm login（AIサムネ用）。失効してもクリーンなグラデにフォールバックし停止しない。
  • 既存チャンネルの動画は混在回避のため限定公開化を推奨。
  • 画像生成は Workspace アカウントのまま（YouTube と分離・公開面に出ない）。

# ⑧ 匿名 YouTube チャンネル準備手順（D1=b）

公開先を匿名チャンネルに確定するための**手動セットアップ**。ここが済めば、以降の自動化（タイトル/サムネ/プレイリスト）はこのチャンネルに対して動く。

> 補足: NotebookLM と Gemini 画像生成（Nano Banana）は会社 Workspace アカウントのまま使う。**YouTube チャンネルはそれとは別の匿名アカウント**にする（チャンネル公開面に個人情報を出さないため）。

## 手順

1. **専用 Google アカウント or ブランドアカウントを用意**
   - 身バレ防止のため、本名と紐づかない新規 Google アカウントを推奨（または既存アカウント配下に「ブランドアカウント」を作成）。
   - チャンネル名・ハンドルは匿名ブランド名にする。

2. **YouTube チャンネルを作成**
   - youtube.com → チャンネル作成（ブランドアカウント推奨）。
   - アイコン（800×800）／バナー（2560×1440・セーフゾーンに価値提案）を設定。
   - **電話番号認証**を済ませる（カスタムサムネのアップロードに必須）。

3. **カテゴリ別プレイリストを5つ作成**（計画 §2）
   - 📄 論文ななめ聴き ／ 🗞 AIニュース ／ 🛠 AI開発メモ ／ 💰 ビジネス ／ 🧪 学びと科学
   - 各プレイリストの URL（`...list=PLxxxx`）から **playlist ID を控える**（③ 実装時に settings.yaml へ）。

4. **Google Cloud で OAuth クライアントを作成**
   - console.cloud.google.com → 新規プロジェクト → **YouTube Data API v3** を有効化。
   - OAuth 同意画面：User type=外部、テストユーザーに自分のアカウントを追加。
   - 認証情報 → OAuth クライアント ID（**デスクトップアプリ**）→ JSON をダウンロード。
   - `credentials/youtube_client_secret.json` に配置。

5. **認証を実行**
   - `uv run automator auth youtube`
   - ブラウザが開いたら、**必ず手順1の匿名チャンネルのアカウント**で承認する（既存 `@denden-yg7kd` と取り違えない）。
   - `credentials/youtube_token.json` が生成される。

6. **確認**
   - テストで1本アップロードし、**反映先が新チャンネルである**ことを確認。
   - `settings.yaml` の `youtube.privacy_status` などを新チャンネル向けに調整（プレイリストのマップ化は ③ 実装時）。

## 補足
- 既存 `@denden-yg7kd` の 136 本は、混在を避けるため**限定公開化**を推奨。
- このチャンネル用アカウントの cookie は **YouTube 用のみ**。Gemini 画像生成は引き続き NotebookLM と同じアカウントの cookie を使う（用途を分離）。

# Video character set v2

`Presentation1.pptx` で手動調整された1920×1080の配置を動画側で再現する素材。

- `metan.png`: 紫ノ宮澪。画面左へ置く右向きの説明ポーズ。
- `metan_open.png`: 澪の口開き差分。元絵へ口元だけを局所合成。
- `zunda.png`: 麦野透。高精細化した閉口差分。
- `zunda_open.png`: 透の口開き差分。元絵へ口元だけを局所合成。

素材キャンバスの透明余白は配置情報を兼ねるため、正規化時に左右を自動トリムしない。
画面上の基準は澪505×875px、透186×677px。澪は左端、透は右端から約95px内側へ置く。

# Unified character masters v1

先生と少年の絵柄を統一した確認用マスターです。

- `teacher.png`: 先生の透過全身立ち絵
- `boy.png`: 少年の透過全身立ち絵
- 生成元: `tmp/character_gen/style_unification/teacher_boy_unified_v1.png`

## 統一方針

- 先生の確定済みイラストをスタイル基準にした。
- 二人を一枚の画像として同時生成し、輪郭線、虹彩、髪のハイライト、服の皺、陰影の段階を同一にした。
- 少年の D3 の特徴（丸顔、わずかな上目遣い、純朴さ、少し頼りない姿勢）は維持した。
- 同一生成画像から個別に切り出したため、個別生成による画風の再分岐を避けている。
- 背景は外周から連続する領域だけを透過し、白衣と白いインナーを維持した。

現行の `metan*.png` / `zunda*.png` は上書きしていません。動画へ組み込む際は、口閉じ・口半開・口開きの差分をこのマスターから作成します。
